# ✦ Yuda Dwi Putra — Portfolio & Creative Studio (v2.0)

> **making ( ) things is the job.**
> **loving it is the ( ) bonus.**

A minimalist, brutalist-editorial personal portfolio & creative studio website crafted with **React 19**, **Vite**, and **Tailwind CSS v4**, inspired by the typographic rhythm, visual parentheses `( )`, and bilingual voice of [Kenji Lambert](https://www.kenjilambert.com/).

---

## ✨ Key Features

- **4-Corner Fixed Frame Navigation**:
  - Top-Left: Interactive stamp monogram (`YDP.26`) with dynamic color cycling.
  - Top-Center: Instant bilingual toggle (`EN / ID`) + live mode switch (`Personal Portfolio` vs. `Creative Agency`).
  - Top-Right: `work` (`karya`) archive view.
  - Bottom-Left: `about` (`tentang`) biography, experience & awards view.
  - Bottom-Right: `studio` interactive copywriting framework & live bio generator.
- **Interactive `( )` Parenthesis Artifacts**:
  - Click or hover inside the hero parentheses `( )` to expand and cycle custom vector/3D-style stickers.
- **4-Font Editorial Typography System**:
  - **Anton** (`--font-stamp`) for massive brutalist headlines and scrolling marquees.
  - **Archivo** (`--font-display`) for geometric parentheses and structural accents.
  - **Plus Jakarta Sans** (`--font-ui`) for crisp neo-grotesque body copy.
  - **Instrument Serif** (`--font-accent-serif`) for editorial italic callouts.
- **"Built Around a Single Idea" Case Studies**:
  - 3-column editorial project headers paired with horizontal draggable 4:5 visual artboard carousels and full-screen case study modals.
- **Mega Email Marquee Footer**:
  - One-click email copy + `Elsewhere` social index + `Contact page →`.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
